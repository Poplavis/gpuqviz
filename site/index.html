快速上手

三行代码，把量子电路变成 3D 动画

# 安装
pip install gpuqviz[qiskit]

# 一行出片
from gpuqviz import export_html
from qiskit import QuantumCircuit

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)

export_html(circuit=qc, out="bell.html", title="贝尔态演化")
# 双击 bell.html 即可打开交互式 3D 播放器

MPS 规模化

20+ qubit χ 截断演化，SWAP 路由，约化分析量直喂渲染层

from qiskit import QuantumCircuit
from gpuqviz import ProVisualizer

qc = QuantumCircuit(2)
qc.h(0); qc.cx(0, 1)

viz = (ProVisualizer(circuit)
       .with_shots(shots=4096, seed=42)
       .with_noise(("depolarizing", 0.05))
       .analyze(pauli=["ZZ"], entanglement=True))

report = viz.report()        # 测量 / 纠缠 / Pauli 期望 —— 可导出核对
viz.export_video("noisy.mp4")  # 含噪演化动画（Bloch 收缩自动呈现）

专业轨道的全部数值由契约测试对拍 qiskit / Aer 锁定 （精确量 1e-10、全电路含噪 1e-6）——详见 文档 · 专业轨道。

CLI 命令

无需写代码，一行命令演示内置算法

gpuqviz demo --list                    # 列出内置算法
gpuqviz demo --algo grover             # 一行命令演示（默认 HTML）
gpuqviz demo --algo qft --format mp4   # 指定输出格式
gpuqviz demo --algo bell --engine pyqpanda  # 切换模拟引擎
